1. 目标

在手机上有一个粉红色的贪吃蛇游戏，图标放在主屏幕，点开就玩，费用为零。不追求上架应用商店，但保留日后升级的路径。

6. 手机上"添加到主屏幕"

iPhone (Safari): Open the URL → tap the Share button (square with arrow) → Add to Home Screen → Add.

Android (Chrome): Open the URL → tap the ⋮ menu → Add to Home screen (or Install app) → Add.

之后从主屏幕图标打开即为全屏无地址栏；第一次打开后离线也能玩。

7. Windows 用户的两个注意点

  • iOS 原生开发需要 Mac。 Xcode 只能在 macOS 运行，所以 B 路必须走 Expo + EAS 云构建，让 Expo 的服务器代为编译 iOS 包。
  • Android 可在 Windows 本地完成全部流程。 只要 Android，B 路成本降到 25 美元一次性。

8. 不做的事

本轮不做：音效、关卡、多人、皮肤切换、应用商店素材。以上都属于 B 路或后续迭代。
